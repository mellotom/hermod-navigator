13

cv in · setup

hrm_13
[ track ] › [ y ] cv-gate in
active track note: cv/gate a+b or c+d → notes on the selected track, quantized c0–c10
same menu
active track mod: cv a–d → unquantized 16-bit mod. one input can’t be note and mod at once
[ tr 1–8 ] › inputs
per-track routing: input note a+b / c+d, input mod a–d. stays routed when the track isn’t selected
cv a–d range
−5 › +5 (default) · 0 › +5 · −2.5 › +2.5 · −1 › +1. match your sequencer: 0 › +5 for 0 V-up pitch
gate capture
0–20 ms wait between gate and cv read. raise it if notes land wrong (slewed or gliding cv)
cv pitch offset
±60 st per input: puts the source on the right octave*
14

record a sequencer

hrm_14
[ y ]+turn [ encoder ]
in step: pattern length to match the sequencer’s loop (see 04)
[ rec ]
overdub: keeps adding on every pass
[ x ]+[ rec ]
hard rec: replaces the selected track only. the way to swap a line
[ y ]+[ rec ]
looper: length is set when you stop — no step counting
[ rec ] punch in
waits for the first incoming note (note tracks only)
[ tr ] › player
mute affects input no = mute silences the recorded notes, the live sequencer still plays through

note track = quantized notes you can edit in step. 1 voice ► modulation + input mod = raw cv, keeps glides.

hrm_16

17

note fx

hrm_17
arpeggiator
style · rate 1/1–1/64 · octave ±5 · gate 0–200% · re-trig (note / bars) · repeat x1–16. put hold first to run it hands-free
chance
play / skip by %. lot rolls once per bar · beat · step group. chance = velocity: odds per note. sync + sync chance guard the downbeats
echo
note repeats: time · 0–16 · fade velocity / gate / pitch. pitch up and down both set = alternates
euclid*
steps + fills 1–32 · rate · rotate · reset. note input in = plays the held notes; a fixed note passes input on, so stack several for polymeters
glide*
linear · exp · smooth, 0–2500 ms then 3 – 60 s
harmonizer
adds up to 4 notes ±24 st. origin off drops the played note
hold*
hold (toggle notes) or relatch (new chord each gesture) · max notes · reset
randomizer
note ±12 · octave ±5 · velocity · length · chance per note
ratchet
splits each note at rate · gate · mod amount / speed stretch and shrink lengths
register*
turing-style: seed · rate · bits 2–16 · chaos (0 / 100% = locked) · center · span · steady. re-seeds on unmute
scale
color › scale · key · stick up / down / filter / odd · trsp ±36 before correcting. after random sources
swing
groove 50% = straight · sync (1/16 classic) · accent · human

order matters: arp › harmonizer ≠ harmonizer › arp. two of the same effect is fine.

cv ranges per input: settings › cv-gate in
18

cv fx

hrm_18
envelope
ahdsr + curves · depth · offset. mode gate on / trig / wait ahd · sidechain any or one note · dest mod 1–4 / pb / at / cc
lfo
sine · tri · ramp · square · rand. sync 1/64–128/1 or free 0.1 Hz – ~1 kHz · range ±100% (− inverts) · offset · phase · mute w/ track*
dest mod
layout 2 voices ► mono + modulation: comes out the 2nd voice cv; its gate is still free
mute / delete
sends the default: envelope = offset, lfo = centre
zipper noise
on a fast vca: slew it, or a ~1.5–2 kHz low-pass (1 kΩ + 100 nF)
20

modmatrix · patch tips

hrm_20
[ effects ] › [ y ]
4 lanes per track: cv a–d, cc 1–119 or recorded mod 1–4 → any fx parameter
[ pad 2 · 6 · 10 · 14 ]
attenuverter ±100% · polarity · offset. it adds to the parameter, you can still turn it
ride → replay
record a knob or cv as mod 1–4, it drives the fx per pattern
self-patch
lfo / envelope out a mod voice → cv c → modmatrix → another effect’s parameter
self-patch
a spare gate out → gate a–d set as trig generator ([ tr ] › inputs): new pattern every hit · trig generator mod = new mod lane, notes kept*
19

convert · route

hrm_19
mod to note
cv / cc → notes. s&h on note-on or every 1/64–1/1 · note min / max · mono track · only while playing
note to cc
note / velocity / on-off → a cc · default value when idle · pass notes
filter
passes a note or mod range; min above max blocks it instead
bernoulli*
coin-flips each event to midi path a or b by %
midi output*
taps the chain mid-way to a midi port. before a harmonizer = plain notes out, chords on cv
