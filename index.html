02

recording

hrm_02
[ rec ]
arm overdub (default) on the selected track; starts with [ play ] or live while playing
[ x ]+[ rec ]
hard rec: overwrites old notes *
[ y ]+[ rec ]
looper rec: length set when you stop *
[ x ] [ y ]+[ rec ]
multitrack rec: all routed tracks *

* factory defaults. reassign: record settings › shortcut x / y / x+y — hard rec, multitrack, looper, punch-in or nothing.
